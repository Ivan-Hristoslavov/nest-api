# Какво трябва да се направи

Осем стъпки. Подредени така, че нищо да не зависи от нещо под него.

Какво точно да пишеш на всяко място — в [ЗАМЕНИ.md](ЗАМЕНИ.md).

---

## 1. Купи домейн и го насочи

Всичко останало зависи от този адрес. Докато го няма, имейлите сочат към твоя лаптоп.

```bash
# в .env
APP_PUBLIC_URL=https://твоя-домейн.bg
CORS_ORIGINS=https://твоя-домейн.bg
```

## 2. Попълни фирмените данни

`public/index.html`, блокът `COMPANY` най-долу. Шест стойности: име, ЕИК, адрес, имейл, доставчик на поща, дата.

След това контактният бутон се включва сам.

## 3. Дай трите правни страници на юрист

Общи условия, Поверителност, GDPR. Написани са срещу това, което кодът наистина прави — това е трудната половина и е свършена. Но не са правен съвет.

## 4. Завърти паролите

Парола за базата и Supabase ключовете — от Supabase Dashboard. `API_KEY` — измисли нов.

Старите са минавали през чат в чист текст.

## 5. Направи плановете в живия Stripe

Три продукта: €19, €49, €99 на месец, без ДДС. По един payment link за всеки.

На всеки линк:
- сложи metadata `plan` = `starter` / `pro` / `business`
- включи събиране на адрес за фактуриране
- включи събиране на ДДС номер

После замени шестте стойности в `.env` и сложи `STRIPE_SECRET_KEY` и `STRIPE_WEBHOOK_SECRET`.

Webhook endpoint-ът е:

```
https://твоя-домейн.bg/api/v1/billing/webhook
```

Провери, че се вижда:

```bash
curl https://твоя-домейн.bg/api/v1/billing/plans
```

Трябва да върне `"enabled": true` и трите плана.

## 6. Включи имейлите от Stripe

Два ключа в Dashboard. Без тях клиентът не получава нито разписка, нито фактура.

- Settings → Customer emails → **Successful payments**
- Settings → Billing → **Email finalized invoices**

Фактурата я издава Stripe, не ние. В кода няма нищо за писане.

## 7. Оправи пощата

Сложи `SMTP_FROM` на адрес от твоя домейн вместо личния Gmail. После провери:

```bash
curl -H "x-api-key: КЛЮЧЪТ" https://твоя-домейн.bg/api/v1/billing/mail/health
```

Пощата носи и ключовете, и алармите. Не тръгне ли, всеки платен акаунт става тикет за поддръжка.

## 8. Напълни каталога

Сега вътре има 7 доставчика и 8 артикула. Праговете, под които сайтът си мълчи за бройките, са 20 доставчика, 250 артикула и 1000 промени в цените.

Добави свои доставчици и пусни една истинска поръчка през `POST /discovery/basket`. Първото търсене при нов доставчик отнема 6–20 секунди, после се кешира.

Преди да добавиш доставчик — прочети условията му. `robots.txt` се спазва автоматично, условията за ползване не са машинно четими и остават човешко решение.

## Пускане

```bash
docker build -t stoclify .
```

```bash
docker run --env-file .env -p 3000:3000 stoclify
```

Провери, че диша:

```bash
curl https://твоя-домейн.bg/health
```

## Първата седмица след това

Гледай тези три:

```bash
curl https://твоя-домейн.bg/api/v1/stats
```

Това са бройките, които печата началната страница — и най-бързият начин да видиш дали обиколките работят.

```bash
npm run schema:log
```

Трябва да предлага **седем** заявки — пет за чужди ключове и две за check constraint-ите на `shops`. Появи ли се осма, нещо се е разминало между кода и базата.

И Sentry, ако си сложил `SENTRY_DSN`. Иначе сривовете остават само в лога.
